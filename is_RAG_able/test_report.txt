# Metric explanations:
# precision: Of all samples predicted as this class, the proportion that are actually this class (true positive rate among predicted positives).
# recall: Of all actual samples of this class, the proportion that are correctly predicted (true positive rate among actual positives).
# f1-score: Harmonic mean of precision and recall, reflecting the balance between them.
# support: The number of true samples of this class in the dataset.
# accuracy: Overall proportion of correctly predicted samples.
# macro avg: Unweighted mean of the metric across all classes.
# weighted avg: Mean of the metric across all classes, weighted by the number of true samples for each class.
